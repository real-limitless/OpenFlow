## Wire format

- **Type string:** `n8n-nodes-base.plivoTool`
- **Aliases:** (none) — the base `n8n-nodes-base.plivo` node has `usableAsTool: true` which registers the Tool variant programmatically
- **Inputs:** `main` x 1
- **Outputs:** `main` x 1
- **Credentials:** `plivoApi` (required) — Basic auth with Auth ID (username) + Auth Token (password)
- **$fromAI() support:** All scalar parameters (from, to, message, answer_url, media_urls, answer_method) accept AI-populated values generated by the n8n AI Agent when the tool is invoked

## Parameters

The parameters are identical to the base Plivo node, accessible via the AI Agent's Tools panel. No separate tool-specific configuration exists. The node shares the same resource/operation structure:

### Resource selection

| name | type | default | required | notes |
|------|------|---------|----------|-------|
| resource | options | `sms` | yes | One of: `call`, `mms`, `sms` |

### Call · Make a voice call

| name | type | default | required | notes |
|------|------|---------|----------|-------|
| from | string | — | yes | Caller ID in E.164 format |
| to | string | — | yes | Destination phone number |
| answer_url | string | — | yes | URL returning Plivo XML for call handling |
| answer_method | options | `POST` | yes | HTTP verb: `GET` or `POST` |

Maps to `POST /v1/Account/{auth_id}/Call/` with body `{ from, to, answer_url, answer_method }`.

### SMS · Send an SMS

| name | type | default | required | notes |
|------|------|---------|----------|-------|
| from | string | — | yes | Plivo phone number (sender ID) |
| to | string | — | yes | Recipient phone number |
| message | string | — | yes | SMS text content |

Maps to `POST /v1/Account/{auth_id}/Message/` with body `{ src, dst, text }`.

### MMS · Send an MMS

| name | type | default | required | notes |
|------|------|---------|----------|-------|
| from | string | — | yes | Plivo phone number (sender ID) |
| to | string | — | yes | Recipient phone number |
| message | string | — | no | Text body (optional for MMS) |
| media_urls | string | — | no | Comma-separated media attachment URLs |

Maps to `POST /v1/Account/{auth_id}/Message/` with body `{ src, dst, text, type: 'mms', media_urls }`.

## Runtime behavior

### Input

Each input item is processed independently. Parameters may be populated by the AI agent via `$fromAI()` dynamic parameter population when the tool is invoked from an AI Agent node.

### Output

Each successful API call produces one output item containing the raw Plivo API response envelope: `{ api_id, message, message_uuid[] }` for SMS/MMS; `{ api_id, message, request_uuid }` for Calls.

### Errors

HTTP errors from the Plivo API (4xx/5xx) are wrapped in `NodeApiError`. Standard n8n `continueOnFail` handling applies.

### Expressions

All string parameters accept expression strings, including `$fromAI()` references for AI agent invocation.
