# Onfleet Tool

AI agent tool variant of the Onfleet node. Wraps the Onfleet REST API (v2, base URL `https://onfleet.com/api/v2`) for last-mile delivery operations within an AI Agent. Shares the same 8 resources and operations as the base `n8n-nodes-base.onfleet` node but is registered in the AI Agent's Tools panel rather than the standard workflow palette.

## Wire format

- **Type string:** `n8n-nodes-base.onfleetTool`
- **Aliases:** (none)
- **Inputs:** `main` × 1
- **Outputs:** `main` × 1
- **Credentials:** `onfleetApi` (API-key-based HTTP Basic Auth)

### Credential requirements

The `onfleetApi` credential stores a single API key string. Requests are authenticated as HTTP Basic Auth with the API key as the username and an empty password, targeting `https://onfleet.com/api/v2`.

## Parameters

This node exposes the same resources and operations as the base `n8n-nodes-base.onfleet` node. The following summary is reproduced at a high level of abstraction.

### Resource selector

The user first selects a resource from: Administrator, Container, Destination, Hub, Organization, Recipient, Task, Team, Worker, Webhook.

### Resource operations

| Resource | Operations | Key parameters |
|----------|-----------|----------------|
| Administrator | Create, Delete, GetAll, Update | name, email, phone, isReadOnly |
| Container | Get, Add Task, Replace Tasks | containerType (`ORGANIZATION`/`WORKER`/`TEAM`), containerId, taskId |
| Destination | Create, Get | address object (parsed or unparsed), optional location [lng, lat] |
| Hub | Create, GetAll, Update | name, address |
| Organization | Get, Get Connected Organization | optional organizationId |
| Recipient | Create, Get, Update | name, phone, skipSMSNotifications |
| Task | Create, Clone, Complete, Delete, GetAll, Get, Update | destination, recipients, scheduling, autoAssign, completionDetails, barcodes, dependencies, custom fields, etc. |
| Team | Auto Dispatch, Create, Delete, Get, GetAll, Get Estimated Time, Update | name, workers, managers, hub, autoDispatch config |
| Worker | Create, Delete, Get, GetAll, Get Schedule, Update | name, phone, vehicle, teams, capacity |
| Webhook | Create, Delete, GetAll | url, trigger (numeric event code), name, threshold |

For full parameter details, refer to the base `n8n-nodes-base.onfleet` spec.

## Runtime behavior

### Input

Each input item is processed independently. Parameters support n8n expressions (`{{ }}`). The resource and operation selectors also accept dynamic expressions.

### Output

On success, each input item produces one output item containing the full Onfleet API response body under `json`. List operations fan out: one output item per array element.

### AI tool semantics

As a Tool variant, this node:

- Is visible in and selectable from the AI Agent's Tools panel (not the main workflow palette).
- Supports `$fromAI()` dynamic parameter population: any parameter can be left for the AI model to fill in at runtime based on conversation context and the `key`/`description` hints provided.
- Parameters marked with the AI stars icon in the UI will have their values generated by the LLM.
- Uses the same parameter schema as the base `onfleet` node — no special tool-only parameters are added.

### Errors

- API errors (4xx/5xx) are thrown unless `continueOnFail` is set, in which case the error item passes through with an `error` property.
- Missing required parameters throw descriptive errors.

### Expressions

All parameter values accept n8n expressions. The `$fromAI()` function is available for AI-driven parameter population.

## Acceptance tests

### Test: Create task via AI agent tool

**Given** input items:
```json
[{ "json": {} }]
```

**Parameters:**
```json
{
  "resource": "Task",
  "operation": "Create",
  "destination": {
    "address": {
      "unparsed": "2829 Vallejo St, SF, CA, USA"
    }
  },
  "recipients": [
    { "name": "Blas Silkovich", "phone": "650-555-4481" }
  ],
  "notes": "Test delivery"
}
```

**Expect** output[0] to contain `json.id` (non-empty string), `json.shortId`, `json.trackingURL`, `json.state` (number), `json.destination`. Output item count is exactly 1.

### Test: GetAll tasks with date filter

**Given** input items:
```json
[{ "json": { "from": 1700000000000, "to": 1700100000000 } }]
```

**Parameters:**
```json
{
  "resource": "Task",
  "operation": "GetAll",
  "filters": {
    "from": "={{ $json.from }}",
    "to": "={{ $json.to }}"
  }
}
```

**Expect** output[0] is an array (possibly empty), each element with `id`, `state`, `timeCreated`.

### Test: $fromAI() parameter population

**Given** the node is connected as a tool to an AI Agent.

**Parameters:**
```json
{
  "resource": "Recipient",
  "operation": "Create",
  "name": "={{ $fromAI('recipientName', 'Name of the delivery recipient', 'string') }}",
  "phone": "={{ $fromAI('recipientPhone', 'Phone number of the delivery recipient', 'string') }}"
}
```

**Expect** when the AI Agent executes, the LLM populates `name` and `phone` from conversation context. The tool issues a POST to the Onfleet API with those values and returns the created recipient object.

### Test: Error on missing required parameters with $fromAI() fallback

**Given** input items:
```json
[{ "json": {} }]
```

**Parameters:**
```json
{
  "resource": "Recipient",
  "operation": "Create"
}
```

**Expect** a thrown error because `name` and `phone` are required and not provided. If `continueOnFail` is enabled, the item passes through with an `error` property.
